# PrismQuest Soundscape, Version 1

Original procedural synthesis generated by `tools/generate_audio.py`.
No third-party recordings, samples, sample libraries or music tracks are used.
No microphone recording or network music streaming is involved.

- `ambient.wav`: 48-second phase-continuous harmonic loop with overlapping soft
  D-minor/add-nine, B-flat-major-seven, F-add-nine and suspended-C colors, and a
  sparse bell figure. Mono PCM, 22.05 kHz, 16 bit.
- `undertone.wav`: quiet, phase-continuous 8-second combat undercurrent.
- `impact`, `spell`, `critical`, `encounter`: brief, softened combat textures.
- `victory`: a small resolving interval, used only when a larger reward does not
  take priority.
- `level`: a rising crystalline arpeggio.
- `find_soft`, `find_rare`, `find_prismatic`: increasingly rich discovery cues.
  Common drops do not receive an item sound.
- `soundscape-preview.wav`: a 12-second developer/player preview, not an extra
  runtime layer. It contains ambience, combat textures, level-up and Rare cues.

The versioned manifest records exact file hashes, duration, peak and RMS.
The synthesis tool removes DC, smooths one-shot boundaries and enforces headroom.
The game decodes the packaged buffers once; it does not synthesize them during
combat. Keep this released `v1` URL/content stable; use a new folder version for
future replacements so long-lived local browser caches cannot serve stale audio.

Playback uses one browser AudioContext, user-gesture activation, finite voices,
separate music/effects buses, conservative gains and a final dynamics limiter.
Web Audio gesture/lifecycle guidance follows the
[MDN best-practices reference](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices).
